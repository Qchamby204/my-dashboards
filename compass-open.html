Storage, privacy and recovery

The public launcher contains no ranked profile or assessment text. It only accepts the two verified Compass files above. File contents are checked before their code is allowed to run.

Remembering a file stores a copy in this browser. Reflections use the Compass's existing browser storage. These records are not encrypted or automatically synced. Other scripts on the same site or someone with access to this browser profile could read browser storage. Do not enter confidential client information.

Use the Compass's Data & backup controls for reflections. Keep the original HTML file separately. Clearing browser data may remove both the remembered file and your reflections. This launcher does not read or change your other dashboards' records.

To select a different approved copy or forget the remembered file, open launcher settings. Forgetting the file does not delete Compass reflections.
